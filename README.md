# Ashley Chen — Personal Website

A responsive personal website for Ashley Chen, full stack engineer based in Taichung, Taiwan.

## Stack

Plain HTML and CSS. No dependencies, build process, tracking, or external fonts.

## Edit

Update `index.html` to change content and styles. Case studies, experience, skills, and education are all in that one file.

The page is bilingual (English by default, Traditional Chinese via the toggle or `?lang=zh`). Each piece of text has an `.en` and a `.zh` version; CSS shows the one matching `html[data-lang]`, and the choice is remembered in localStorage.

## GitHub Pages

Publish the `main` branch from the repository root using Settings → Pages → Deploy from a branch.

Intended address: https://ashley0821.github.io/
